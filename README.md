# otter-device-linkとは
web上でスマホを点滅させてespとかにssidとパスワードの情報を送る。

https://ishikishik.github.io/otter-device-link/

# 通信プロトコル
| 記号 | 緑 | 黒 | 合計 |
|---|---|---|---|
| ビット 0 | 1T | 1T | 2T |
| ビット 1 | 1T | 3T | 4T |
| 区切り / 終わり | 4T | 1T | 5T |
| 開始の合図 | 8T | 4T | 12T |

## チェックサム
- 合計バイトの下位8bitを送信して照合する。
- 誤り訂正はないのでミスったら再送が必要
## 閾値
- 一番くらい値と一番明るい値の中間とする(幅の1/8以上の差が必要)
- 10msごとに補正する

## Tの判別
- 緑が黒のおおよそ2倍で緑が160ms以上

## 機材
- [これ](https://akizukidenshi.com/catalog/g/g108910/)を使用しています。データシートの通り緑に一番敏感です。センサーを変えたら光らす色を変えるべきかもしれません。
